# 1.1 模型到底是什么

## 一句话

**模型就是一个"文件"**——一个几百 GB 的数学参数文件，加载到 GPU 上之后，能根据你输入的文字预测下一个最可能出现的词。仅此而已。

---

## 模型 ≠ 产品

| 你看到的 | 实际上是 |
|----------|----------|
| ChatGPT | 产品（套了壳的 GPT 模型 + 网页界面 + 账号系统） |
| Claude.ai | 产品（套了壳的 Claude 模型 + 网页界面 + 账号系统） |
| Claude Code | 工具（调用 Claude 模型的命令行程序） |
| DeepSeek | 既是公司名，也是模型名（DeepSeek-V3 / R1） |

**模型本身没有界面、没有按钮、没有登录。** 你永远"用"不了模型本身——你用的永远是通过 API 或产品间接调用它。

---

## 主流模型家族

### Claude（Anthropic）
```
Claude Opus 4.8  → 最强，最贵，复杂推理
Claude Sonnet 4.6 → 性价比之王，日常开发首选
Claude Haiku 4.5  → 最快最便宜，简单任务
```
- **特点**：代码能力强、遵循指令好、长上下文 200K
- **你的 Claude Code 用的就是这个**

### GPT（OpenAI）
```
GPT-5        → 最强
GPT-4o       → 多模态（能看图片）
GPT-4o-mini  → 便宜快速
```
- **特点**：多模态好、生态最成熟、插件最多

### DeepSeek（深度求索）
```
DeepSeek-V3  → 通用模型
DeepSeek-R1  → 推理模型（会"思考"）
```
- **特点**：开源、便宜、中文好
- **你用的 API 很可能是这个**

### Gemini（Google）
```
Gemini 2.5 Pro → 最强，200 万 token 上下文
Gemini 2.5 Flash → 快速版
```
- **特点**：上下文超长、多模态原生支持

### 开源模型
```
Qwen（阿里）、Llama（Meta）、Mistral
```
- **特点**：免费、可本地跑、但需要自己搭环境

## 模型能力差异：同一句话，不同模型表现完全不同

Prompt: "用 Python 写一个文件整理 Agent，能根据文件扩展名自动分类移动到对应文件夹"

- **Claude Opus** → 一次性写出完整代码，带错误处理，注释清晰
- **Claude Sonnet** → 能写，但可能需要你补一些边界处理
- **GPT-4o mini** → 能写，但可能漏掉某些文件类型的处理
- **DeepSeek-V3** → 能写，中文注释很详细，但可能过度设计

**不是越贵越好，是越匹配任务越好。**

## 模型版本号到底在说什么

```
Claude Sonnet 4.5 → Claude Sonnet 4.6
                            ↑
                     这 0.1 的差异可能意味着：
                     - 代码能力提升 15%
                     - 价格不变
                     - 或者：某些 benchmark 更好，但实际你感知不到
```

规则：
- **大版本号变化（3.x → 4.x）**：重大升级，必须关注
- **小版本号变化（4.5 → 4.6）**：优化迭代，可以跟
- **别追版本号**：新版本可能在某些任务上反而更差（regression）
- **看 benchmark 不如自己测**：用你自己的任务 prompt 测两次，对比结果

## 模型的三要素

选模型看三个东西：

```
1. 智商（推理能力）
   → 复杂任务需要高智商（Opus / GPT-5 / R1）
   → 简单翻译、摘要不需要

2. 速度（延迟）
   → 交互式场景要快（Haiku / Flash）
   → 批处理可以等

3. 价格
   → 每百万 token 的价格（见 1.4 Token 经济学）
   → Opus 可能比 Haiku 贵 10-30 倍
```
