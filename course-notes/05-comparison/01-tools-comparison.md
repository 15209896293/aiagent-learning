# 5.1 Claude Code / Trae / ZCode 对比

## 先看一张表

| | Claude Code | Trae | ZCode |
|---|---|---|---|
| **形态** | 终端（CLI） | IDE 插件 | IDE 插件 |
| **开发商** | Anthropic | 字节跳动 | 国内团队 |
| **默认模型** | Claude Sonnet | GPT-4o / Claude | 可配 |
| **收费** | 你的 API Key 付费 | 免费（字节买单） | 你的 API Key |
| **MCP** | ✅ 完整支持 | ❌ | ❌ |
| **Skills** | ✅ | ❌ | ❌ |
| **Hooks** | ✅ | ❌ | ❌ |
| **多 Agent** | ✅ Workflow | ❌ | ❌ |
| **中文** | 好 | 很好 | 好 |
| **上手难度** | 中（命令行） | 低（GUI） | 低（GUI） |

---

## Claude Code — 最强大也最需要学习

### 优势
- **能力最强**：MCP + Skills + Hooks + 多 Agent = 能做任何 IDE 插件做不了的事
- **灵活度最高**：CLI 界面 = 没有 GUI 限制，Agent 能做任何操作
- **控制力最强**：你看到 Agent 的每一步操作，能精确打断和引导
- **可扩展**：写自己的 Skills、配 MCP Server、设 Hooks

### 劣势
- **学习曲线**：命令行界面，没有按钮和菜单
- **收费**：每次调用走你的 API Key，烧钱风险自己承担
- **容易误操作**：灵活性高 = 出错的代价也高
- **没有代码补全**：Trae 和 ZCode 都有实时补全，Claude Code 没有（它是对话式的）

### 最适合
- 复杂任务：跨多个文件的重构、大规模搜索、项目初始化
- 需要外部工具的场景（MCP 操作浏览器、数据库）
- 你想精确控制 Agent 行为时
- **你已经有它了 — 这是你的主力工具**

---

## Trae — 免费、简单、开箱即用

### 优势
- **免费**：字节跳动目前承担 API 费用
- **上手简单**：装插件 → 侧边栏聊天 → 选中代码就能改
- **代码补全**：实时补全，像 Cursor/Copilot
- **中文优秀**：中文理解和生成都是第一梯队

### 劣势
- **没有 MCP / Skills / Hooks**：能力天花板低于 Claude Code
- **黑盒**：你看不到 Agent 具体做了什么工具调用
- **免费的不确定**：字节可能随时改变收费策略
- **受限于 IDE**：只能在 Trae IDE 里用

### 最适合
- 简单代码修改：改一个函数、加一个组件
- 代码补全（实时补全比 Claude Code 强）
- 你不想花钱的时候
- 快速原型开发

---

## ZCode — 你正在用的另一个

### 特点
- 类似 Trae 的 IDE 插件形态
- 取决于你配了什么模型和 API Key
- 能力取决于底层模型（配 GPT = GPT 的能力，配 DeepSeek = DeepSeek 的能力）

### 最适合
- 和 Trae 类似的场景
- 如果你配的模型比 Trae 默认的好 → ZCode 可能更强
- 作为 Claude Code 的轻量替代（不想打字时用 GUI）

---

## 三个工具怎么配合

```
复杂任务（跨文件重构、数据库操作、浏览器测试）
  → Claude Code（你最强大的工具）

日常开发（写组件、改函数、代码补全）
  → Trae / ZCode（免费 + GUI + 补全）

需要 MCP / Skill / Hook 的高级自动化
  → 只能用 Claude Code

想省钱
  → Trae（免费）或 ZCode（配 DeepSeek）
```

---

## 一个典型的工作流

```
1. 用 Claude Code 做需求分析 + 任务拆解
   "帮我分析赶酒项目的搜索需求，拆成实现步骤"

2. 用 Claude Code 写核心复杂逻辑
   "写搜索 API 的后端实现"

3. 用 Trae 写简单的 UI 组件
   侧边栏选中代码 → "把这个卡片改成圆角"

4. 用 Trae 做代码补全
   写了 import {  → Trae 自动补全你常用的组件

5. 用 Claude Code 做最终审查
   "审查这次所有改动，找 bug 和安全问题"
```

## 选择指南

```
你的水平      → 推荐工具
─────────────────────────────────
初学者        → Trae（无成本、低门槛）
能写命令行    → Claude Code（你应该在这）
想极致省钱    → Trae 主力 + Claude Code 辅助
想极致能力    → Claude Code 主力 + Trae 辅助（你现在）

你的场景      → 推荐工具
─────────────────────────────────
改一个函数    → Trae（更快）
重构整个模块  → Claude Code（更强）
写新功能      → Claude Code 规划 + Trae 执行 UI
调试 bug      → Claude Code（能读日志、跑命令）
学新东西      → Claude Code（能搜索、能深入解释）
```
