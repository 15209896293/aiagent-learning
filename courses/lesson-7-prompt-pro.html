第 7 课 · 结构化 Prompt

从"能跑就行"到"一把过"——让你的提示词精准如手术刀

Prompt 的四个段位

Lv1 "帮我写个网页" — AI 瞎猜，结果随机
Lv2 "用 HTML 写个登录页面" — 指定了技术，但还是粗
Lv3 "你是前端专家。用纯 HTML+CSS 写登录页：邮箱框、密码框、登录按钮。深色背景。只给代码。" — 用了公式
Lv4 上面 + 给出输入输出示例 + 错误处理规则 + 格式模板 — AI 几乎不会出错

你现在大概在 Lv2-Lv3。这节课教你到 Lv4。

模式一：Few-Shot（给示例）

给 AI 看 2-3 个"输入 → 正确输出"的例子，它就能学会你想要的格式。

示例：翻译 Prompt

将中文翻译成英文 JSON：

输入：你好 → 输出：{"zh": "你好", "en": "Hello"}
输入：谢谢 → 输出：{"zh": "谢谢", "en": "Thank you"}
输入：再见 → 输出：
（AI 会输出 {"zh": "再见", "en": "Goodbye"}）

核心道理：AI 是模式匹配机器。你给它看什么模式，它就模仿什么模式。

模式二：Chain of Thought（思维链）

在 Prompt 里加一句"一步一步思考"，AI 会把推理过程写出来。看起来多写了字，但最终答案的正确率大幅提高。

为什么有效？

AI 生成文字是"一个字一个字"往外蹦的。如果它第一个字就错了，后面全错。让它先写推理 → 推理过程纠正了自己 → 最终答案就对了。

这就好比你做数学题：不打草稿容易错，打草稿正确率高。

模式三：带反馈循环

给 AI 一个"自我检查"的步骤：

1. 先写出你的答案
2. 检查你的答案是否符合所有约束
3. 如果不符合，修改后再输出
4. 只输出最终版本

这就叫 Self-Reflection（自反思）。Agent 的核心循环之一，后面 Level 4 会用到。

模式四：强制格式约束

90% 的新手不会这招：指定输出格式。

不指定格式

"列出这个项目的所有文件" → AI 可能用段落、列表、表格……格式混乱

指定格式

"列出项目文件，格式为 JSON：{files: [{name, path, size}]}" → AI 输出标准 JSON，程序可以直接解析
这是 AI 自动化的基础。如果你想让 AI 的输出被另一个程序读取，必须约束格式为 JSON/XML/CSV。

现在动手：把你的日常 Prompt 升级到 Lv4

打开 Cline，把下面这句话发过去，看它的输出质量：

【角色】你是一个 Vue 3 前端开发专家
【任务】写一个待办事项组件 TodoList
【格式】只输出 Vue SFC 单文件组件代码，不要解释
【约束】使用 Composition API + script setup，CSS 用 scoped
【示例参考】样式风格参考 Notion 的简洁设计
【输出格式】先用 2 句话说明设计思路（注释形式），然后给出完整代码

这一课你带走的 3 个概念

1 Few-Shot = 给 AI 看例子，它模仿你的格式

2 Chain of Thought = 让 AI "打草稿"，正确率更高

3 强制格式 = 指定 JSON/XML 输出，让程序能解析
