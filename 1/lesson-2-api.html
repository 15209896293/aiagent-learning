🍕 第 2 课 · 模型 vs API vs API Key

三个词搞混了无数次？用"吃饭"一句话讲清楚

🍳 核心比喻：自己做饭 vs 点外卖

👨‍🍳

方案A：自己部署模型

下载 DeepSeek 全部文件到你的电脑
（约 700GB）
需要一张几万块的显卡
每次用，自己电脑跑

💸 前期投入大，后面免费
🛵

方案B：调 API（你在用的）

发文字给 DeepSeek 服务器
他们的显卡帮你跑
按字数收钱

✅ 不用显卡，按量付费

🍳 模型 = 菜谱和食材（公式+参数）
🏪 DeepSeek 服务器 = 餐厅后厨
🛵 API = 外卖小哥（帮你传话的通道）
🔑 API Key = 你的会员卡号（证明你付钱了）

🔗 你现在"用 DeepSeek"的真实路径

💻 你打字
Cline / Claude Code
→
🔑 带上 API Key
sk-52c14...
→
🏪 DeepSeek 服务器
在云端，不在你电脑
→
🧠 模型运算
几百张显卡同时跑

整个来回通常不到 3 秒

💡 所以你说的"我用 DeepSeek"其实是在说：
"我在自己的电脑上，通过网络，调用 DeepSeek 公司服务器上的模型。按字数付钱。"

🔑 API Key 就是你消费时刷的卡

你现在的 DeepSeek API Key 长这样：

sk-52c140926a4a422f8697a1420be9f3cb

sk 前缀 = "Secret Key"，秘密钥匙的意思。

DeepSeek 看到这个 key → 查到"哦，是 lenovo 在用"→ 调用一次扣几厘钱。

⚠️ 这个 Key 像银行卡密码，不能给别人！

如果别人拿到你的 Key，他就可以用你的账户疯狂调用，花的全是你的钱。你不小心发到 GitHub 上，几分钟就会被机器人扫走，然后账单爆炸。

🤔 "开源模型"为什么还要付钱？

DeepSeek 把模型文件公开了（谁都可以下载），这叫开源。

但运行模型需要显卡。DeepSeek 的服务器跑着几百张显卡，你每次调用他们就消耗电力和算力——这些要钱。

简单说：菜谱免费（开源），但让别人帮你做菜要付人工费（API调用费）。

📋 这一课你带走的 3 个概念

1️⃣ 模型 = 一堆数学参数构成的文件，可以下载到本地，也可以放在云端

2️⃣ API = 你通过网络调用别人服务器上的模型，"点外卖"模式

3️⃣ API Key = 你的身份凭证，DeepSeek 用它来计费，不能泄露
