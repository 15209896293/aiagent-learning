📝 第 4 课 · Prompt 提示词

你跟 AI 的说话方式，直接决定了它有多"聪明"

🗣️ Prompt 就是你跟 AI 说的那句话

Prompt = 提示词 = 你发给 AI 的所有文字。

就这么简单。没有魔法。你说"帮我写个网页"，这句话就是 Prompt。

但是——同样一个问题，不同的人问法不同，AI 的回答质量可以差 10 倍。会提问本身就是一种技能。

👎 vs 👍 看看差距

❌ 烂 Prompt

"写一个登录页面"

→ AI 不知道你要什么风格、什么技术、有没有后端，随便给你一个

✅ 好 Prompt

"用纯 HTML+CSS 写一个登录页面，包含邮箱和密码输入框、一个登录按钮。背景深色，卡片居中。只写代码不要解释。"

→ AI 知道你要什么，一步到位

🧪 万能 Prompt 公式

把下面五个要素填上，AI 的回答就不会跑偏：

🎭 角色
你是谁？
+
🎯 任务
做什么？
+
📐 格式
输出什么？
+
📋 约束
什么不能做？
+
📎 示例
样本？
实际例子：
【角色】你是一个资深前端工程师
【任务】写一个响应式导航栏
【格式】只要 HTML+CSS 代码，不要解释
【约束】不引入任何 JS 框架，纯原生
【示例】风格参考 Apple 官网的导航栏

🛠️ 三个立刻能用的技巧

1. "不要解释，只给代码"

AI 默认喜欢解释。加上这句话，它直接出结果，省一半 Token。

2. "一步一步思考"

遇到复杂问题，加上这句话。AI 会把推理过程写出来，答案正确率高很多。这招就叫 Chain of Thought（思维链）。

3. "你是专家"

虽然 AI 没有真正的人格，但加角色设定会让它输出更专业的内容。"你是前端专家"比"帮我写代码"效果好得多。

🤫 还有一个你看不见的 Prompt

你的 CLAUDE.md 里写的那些规则——"产品经理思维优先"、"听不懂必须问"……这些在每次对话开始前就悄悄塞给了 AI。

这叫 System Prompt（系统提示词）。它决定了 AI 的"人设"和行为方式。

你可以理解成：
• System Prompt = 写在合同里的"员工守则"，AI 始终遵守
• User Prompt = 你每次说的话，也就是"今天干嘛"

⚠️ 注意：System Prompt 也消耗 Token！

你的 CLAUDE.md 越长，每次对话的成本就越高——因为每次 AI 都要先"背一遍员工守则"。所以不是写得越多越好。

📋 这一课你带走的 3 个概念

1️⃣ Prompt = 你跟 AI 说的任意话。好 prompt = 好结果。

2️⃣ 公式：角色 + 任务 + 格式 + 约束 + 示例 = 完美 Prompt

3️⃣ System Prompt = 后台塞给 AI 的"员工守则"，消耗 Token
