# 4.3 什么时候不要用 Agent

## 第一条铁律

> **Agent 不是万能工具。用错场景比不用更糟。**

---

## 场景 1：简单重复操作

```
问题：把 50 个文件里的 "userName" 改成 "username"
Agent 方案：一个个读、改、写（100+ 次工具调用，耗时长）
你应该：IDE 的全局查找替换（Ctrl+Shift+H，3 秒搞定）
```

### 判断标准
```
操作步骤数 < 3 → 手动做
操作重复次数 > 10 → 用批量工具（IDE、sed、脚本）
操作需要判断每个文件 → 才适合 Agent
```

---

## 场景 2：需要精确控制的逻辑

```
问题：写一个支付回调处理，金额精确到分，不能有误差
Agent 方案：写了能跑的代码，但你不知道边界处理有没有遗漏
你应该：自己写，加完整的单元测试，逐行 review
```

### 为什么不适合
Agent 生成代码有**随机性**（temperature > 0）。同一 prompt 问两次，答案可能不同。对于钱、权限、安全相关的代码，你需要的是确定性，不是概率。

### 红线领域
- 支付和计费逻辑
- 权限和认证（不要完全信任 Agent 写的 auth 代码）
- 加密和密钥管理
- 任何"错了就会造成财务损失或安全事故"的代码

---

## 场景 3：安全敏感的代码

```
Agent：我帮你写一个密钥生成函数！
      def generate_key():
          return "my-static-key-2026"  ← 安静但致命

Agent：我帮你写 SQL 查询！
      query = f"SELECT * FROM users WHERE id = {user_id}"
      ← SQL 注入漏洞
```

### 为什么危险
Agent 知道安全最佳实践（参数化查询、环境变量、非对称加密），但它**不保证每次都遵守**。一次不遵守就可能造成安全问题。

### 安全敏感代码清单
- SQL 查询拼接 → 必须自己确认用了参数化
- 密码处理 → 必须自己确认用了 bcrypt/argon2
- JWT 验证 → 必须自己确认算法和过期时间
- 文件上传 → 必须自己确认路径穿越防御
- CORS 配置 → 必须自己确认没有 `*` 通配符

---

## 场景 4：你完全不了解的领域

```
问题：帮我写一个 Rust 的异步 runtime
你的水平：没写过 Rust
结果：Agent 写了 500 行代码，你不能判断它对不对
```

### 为什么危险
**Agent 的输出质量 = 你能判断质量的程度。** 如果你完全不懂一个领域，你就无法验证它的产出。Agent 可能：
- 编造不存在的 API
- 写出有 bug 的逻辑
- 输出看起来正确但跑不起来的东西

### 适用条件
> 使用 Agent 的前提：你有能力在 5 分钟内判断它的产出是否正确。
> 如果不具备这个能力，先用 Agent 学习基础知识，再让它写代码。

---

## 场景 5：需要上下文理解但上下文不够

```
你有一个 100 万行代码的项目
你：帮我理解这个项目的架构
Agent：（只能看到最近的几个文件）
      → 给出的分析不完整，但你看不出来
```

### 为什么不行
Agent 一次只能看到上下文窗口内的内容。对于大型项目：
- 它看不到全部文件
- 它的"架构理解"是基于采样的
- 采样不完整 = 结论不可靠

### 替代方案
- 人工画出架构图，让 Agent 帮你填充细节
- 分模块让 Agent 理解，自己拼全貌
- 用文档和 README 给 Agent 提供全局视图

---

## 场景 6：创造性和战略决策

```
你：我们的产品应该加什么新功能？
Agent：建议加社交分享、AI 推荐、会员系统...

你：我应该选 React 还是 Vue？
Agent：各有利弊，取决于你的需求...
```

### 为什么不行
Agent 没有真正的创造力。它的"建议"是训练数据中常见模式的组合。对于产品决策、技术选型、架构设计：
- Agent 可以提供参考信息（React 和 Vue 的差异）
- Agent 不能替你做决定（它不知道你的团队、用户、业务目标）
- Agent 的"创意"是已有模式的拼接，不是创新

---

## 决策框架

拿到一个任务时，问自己：

```
1. 我能判断 Agent 产出的对错吗？
   → 不能 → 不给 Agent

2. 这个任务的容错率是多少？
   → 零容忍（钱、安全）→ 不给 Agent

3. 手动做要多久？
   → < 5 分钟 → 手动，不给 Agent

4. 任务涉及的文件超过 50 个吗？
   → 是 → Agent 也处理不了，拆成子任务分批给

5. 我需要的是"执行"还是"决策"？
   → 决策 → 不给 Agent（可以让它提供信息辅助决策）
```

**5 个问题全通过 → 适合给 Agent。**
